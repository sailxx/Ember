### 🔥 فلٹر

ایک گرم پارباسی تہہ پوری سکرین کو ڈھانپتی ہے۔ **طاقت** سیٹ کرتا ہے کہ یہ کتنا گھنا ہے۔, **مدھم** اسکرین کو گہرا بناتا ہے (رات کو کم سے کم چمک کے بجائے آسان)۔ پرت ایک قابل رسائی سروس کے ذریعے کھینچی گئی ہے: سسٹم اپنی ونڈو کو قابل اعتماد سمجھتا ہے، اس لیے ٹچز ہر جگہ فلٹر سے گزرتے ہیں، یہاں تک کہ محفوظ اسکرینوں پر بھی۔ Ember کبھی بھی اسکرین نہیں پڑھتا ہے۔ سروس کے بغیر فلٹر واپس "دیگر ایپس پر ڈسپلے" پر آ جاتا ہے، جہاں Android 12+ دھندلاپن کو محدود کرتا ہے اور کچھ اسکرینوں پر ٹیپس کو روکتا ہے۔

### 🌅 شیڈول

تین موڈ: **سورج کی طرف سے** — "جگہ" کے آگے "لوکیٹ" کو تھپتھپائیں، Ember آپ کے نقاط کو ایک بار پڑھتا ہے اور ہر دن کے لیے غروب آفتاب اور طلوع آفتاب کا حساب لگاتا ہے ( NOAA الگورتھم، فون پر ہی); **وقت کی طرف سے** — آپ کے اپنے آن اور آف اوقات; **ہمیشہ** — چالو ہونے پر فلٹر آن رہتا ہے۔ جب تک کوئی جگہ سیٹ نہیں ہو جاتی، "سورج کے ذریعے" آپ کے اپنے اوقات استعمال کرتا ہے (21:00-07:00 بذریعہ ڈیفالٹ)۔ دھندلا پن 0، 15، 30 یا 60 منٹ تک رہتا ہے۔ مرکزی اسکرین پر موجود چارٹ دکھاتا ہے کہ فلٹر اسکرین کو کب اور کتنی مضبوطی سے گرم کرتا ہے۔

### 🎛 ٹائل اور اطلاع

فوری ترتیبات میں Ember ٹائل فلٹر کو ایک نل کے ساتھ آن اور آف کرتی ہے۔ نوٹیفکیشن دکھاتا ہے کہ کیا ہو رہا ہے ("2700 K · 06:48 تک" یا "غروب آفتاب کا انتظار") اور "ٹرن آف" بٹن ہے۔ ریبوٹ کے بعد فلٹر خود ہی واپس آجاتا ہے۔

### 🔒 رازداری

Ember کے پاس ہے۔ **انٹرنیٹ تک رسائی نہیں ہے** — اجازت مینی فیسٹ میں نہیں ہے۔ کوآرڈینیٹس صرف ایپ کی ترتیبات میں محفوظ کیے جاتے ہیں۔

## Ember کے بارے میں

<img src="assets/readme/about-en.svg" width="100%" alt="Ember کے بارے میں">

Ember شروع ہوا۔ **16 اکتوبر 2026** رات کے وقت Android اسکرینوں کو گرم بنانے کے ایک چھوٹے منصوبے کے طور پر۔ یہ مفت اور غیر تجارتی ہے۔ کوئی اشتہارات، اکاؤنٹس، یا تجزیات نہیں ہیں۔ Ember آپ کو ٹریک نہیں کرتا، آپ کا ڈیٹا اکٹھا نہیں کرتا، اور کبھی نہیں کرے گا۔

آپ کی ترتیبات آپ کے فون پر رہتی ہیں۔ اگر آپ شیڈول کے لیے اپنا مقام استعمال کرنے کا انتخاب کرتے ہیں، تو Ember اسے ایک بار پڑھتا ہے اور آلہ پر طلوع آفتاب اور غروب آفتاب کا کام کرتا ہے۔ ایپ کو انٹرنیٹ کی اجازت نہیں ہے۔ [رازداری کی پالیسی](PRIVACY.md)

- [**0.8**](https://github.com/sailxx/Ember/releases/tag/v0.8) — سیٹنگز میں انگریزی کو روسی کے ساتھ ڈیفالٹ بنایا، سفید دائرے کا آئیکن شامل کیا، اور ایکسیسبیلٹی سروس کو فلٹر خود لاگو کرنے دیں۔
- [**1.0**](https://github.com/sailxx/Ember/releases/tag/v1.0) — درجہ حرارت کارڈ کو آسان بنایا اور سلائیڈر کو ہموار کیا۔ کارڈ اور فلٹر بٹن اب آپ کے گھسیٹتے ہی رنگ بدلتے ہیں۔

<summary><b>ترقی</b></summary>

Kotlin 2.2 + Jetpack Compose (مٹیریل 3)، کوئی تھرڈ پارٹی انحصار نہیں۔

```bash
./gradlew assembleRelease     # APK in app/build/outputs/apk/release/
./gradlew testDebugUnitTest   # sunset, sunrise and the filter curve
./gradlew lintDebug           # Android Lint checks
```

JDK 17+ اور Android SDK (پلیٹ فارم 35) کی ضرورت ہے۔ README تصاویر تیار کی جاتی ہیں — ترمیم کریں۔ `tools/readme/strings.json` اور چلائیں `cd tools/readme && npm install && node build.mjs`.

ریلیز کرنے سے پہلے، آلے موڈ میں ان مراحل کو چیک کریں۔:

1. دونوں اوورلے اجازتوں کے ساتھ فوری ترتیبات کے ٹائل کو تھپتھپائیں۔ دونوں میں سے کسی ایک کو دیں اور Ember پر واپس جائیں۔ فلٹر ٹائل کو دوبارہ ٹیپ کیے بغیر ظاہر ہونا چاہیے۔
2. فوری ترتیبات سے فلٹر کو ٹوگل کریں، پھر اسے اطلاع سے آف کریں۔ Ember اور ٹائل کو متفق ہونا چاہئے۔ طاقت کو تبدیل کرنے سے فلٹر بند ہونا چاہئے۔
3. فلٹر فعال ہونے کے ساتھ دوبارہ بوٹ کریں۔ انلاک کرنے کے بعد، فلٹر واپس آنا چاہیے۔ ایکسیسبیلٹی سروس کے ساتھ اور ڈسپلے سے زیادہ دیگر ایپس کی اجازت کے ساتھ الگ سے دہرائیں۔

</details>
